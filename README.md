# 🤖DAD-BOT
This is a Slack bot made with JavaScript in node.js following the Stardance Slack bot guide
</br>
This bot is like a dad. He tells jokes, advices, etc. 
<br>
<br>
<strong>Those are the APIs I used:</strong>
<ul>
    <li>https://catfact.ninja/fact</li>
    <li>https://bored-api.appbrewery.com/random</li>
    <li>https://api.chucknorris.io/jokes/random</li>
    <li>https://api.adviceslip.com/advice</li>
    <li>https://v2.jokeapi.dev/joke/Any</li>
</ul>

## Commands
<strong>Available Commands:</strong>
<ul>
    <li><code>/dad-help</code> - Show help about commands</li>
    <li><code>/dad-ping</code> - Check bot latency</li>
    <li><code>/dad-fact</code> - He tells a good fact to help you</li>
    <li><code>/dad-catfact</code> - He tells a cat fact</li>
    <li><code>/dad-joke</code> - He tells a bad joke</li>
    <li><code>/dad-chuck-norris</code> - He tells a fact about Chuck Norris</li>
    <li><code>/dad-i-am-bored</code> - He tells you random things to do when you're bored</li>
</ul>
